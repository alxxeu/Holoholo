What's new

Holoholo for macOS · Version 0.1.14 · November 19, 2026

Security

  • Other programs can no longer open Holoholo up. Launch options passed from outside, which could switch on remote debugging, are ignored.
  • Companions are recognized by the program's signature, not by the name they report. Companions you allowed before will ask for access once more.
  • Private Space is better protected. The key to its saved tabs now needs Touch ID or your Mac password, and custom CSS from Tweaks no longer applies there (hiding elements, font and tone still do).
  • Updated the web engine to Chromium 156.0.8078.100, which includes security fixes.

Fixed

  • Keyboard shortcuts of extensions now work on any keyboard layout, not only the English one.
